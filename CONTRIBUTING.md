# Contributing to Zenvoice

Welcome to Zenvoice! ❤️ Thank you for your interest in contributing to the future of open-source voice AI. ❤️

Zenvoice is a comprehensive voice agent platform that helps developers build, test, and deploy conversational AI systems with minimal setup. This guide will help you understand the project structure, set up your development environment, and start contributing effectively.

> 🧩 This project is a whitelabeled fork of the open-source [Dograh AI](https://github.com/dograh-hq/dograh) project. Consider contributing improvements upstream too when they aren't Zenvoice-specific.

## 🏗️ Project Overview

### What is Zenvoice?

Zenvoice is a full-stack platform for building voice agents with a drag-and-drop workflow builder. It combines multiple technologies to provide a seamless experience from development to production deployment.

## 🙌 How You Can Contribute

- 🐛 **Report bugs** via GitHub Issues *(link to your fork's repo)*
- 💡 **Suggest features** via Ideas/Discussions *(link to your fork's repo)*
- 🔧 **Submit pull requests**
- 📖 **Improve documentation** The documentation is hosted via mintlify and the code is in `docs/` folder
- 💬 **Join the community**

👉 A great place to start is with issues tagged **`good first issue`**.

> And if you like the project, but just don't have time to contribute code, that's fine. There are other easy ways to support the project:
>
> - Star the project;
> - Tweet about it;
> - Refer to this project in your project's readme;
> - Submit and vote on Ideas;
> - Create and comment on Issues;
> - Mention the project at local meetups and tell your friends/colleagues.

## 🚀 Development Setup

Please refer to our [Development Setup documentation](https://docs.zenvoice.example/contribution/setup).

### Getting Help

**Before You Start**

- Check existing [GitHub Issues](../../issues) for similar work
- Join our community to discuss your plans
- Look for issues tagged `good first issue` for beginner-friendly tasks

**During Development**

- Ask questions in our community
- Reference related issues and PRs in your discussions
- Share early drafts for feedback on complex features

## 💬 Community & Support

Our community is the heart of Zenvoice development:

- **Get Help**: Setup assistance and debugging support
- **Collaborate**: Discuss features and architectural decisions
- **Connect**: Meet other contributors and maintainers
- **Stay Updated**: Learn about contribution opportunities and releases
